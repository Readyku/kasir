# Kasir Readyku

Aplikasi kasir web (bisa dipasang di layar utama HP/tablet, jalan offline) yang tersambung ke Google Sheet milik pemilik toko.
Bagian dari produk template Readyku (readyku.id). Link Kasir untuk toko didapat dari Google Sheet template Readyku, menu Readyku > Siapkan Kasir.

Library: SheetJS Community Edition (Apache-2.0) di folder vendor.
